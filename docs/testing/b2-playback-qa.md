# Private B2 native playback QA

`mobile/lib/main_b2_playback_qa.dart` is a separate debug-only entry point for an operator-controlled fixture. It does not call the production bootstrap/router, create an account, sign or publish Nostr events, initialize analytics, enable playback telemetry, or write feature-flag preferences. Its `initialVideo` exists in memory with synthetic identifiers. It uses the real `DivineVideoPlayerController`, real native view and production `resolvePlaybackSources` / `setSourceWithFallbacks`; the screen shows the selected source and native first-frame observation. Unit tests replace the platform controller and do not establish native playback success.

The operator supplies an owned, public canonical original through `B2_QA_ORIGINAL_URL`. Missing, signed and unrelated original URLs are rejected before player initialization. Supply `B2_QA_RENDITION_URL` to test the normal rendition-first path; omit it to test eligible original routing. Neither fixture URLs nor build logs containing them belong in the repository or public review artifacts. The harness bypasses app feeds and disk caching; production feed cache/prefetch parity is covered separately by package tests.

The debug compile define `B2_PLAYBACK_HOST` accepts `media-b2.divine.video` (default) or `media-b2-cdn.divine.video`. Invalid values retain the old host. Production/release builds always retain the old host, even if an override is supplied. Both exact hosts retain source-loader policy handling: private 404 and generic errors stop; explicit service-unavailable (503) and typed transport failures may fall back. Derivatives are never rewritten onto either B2 host.

For an independently authorized device session, select `lib/main_b2_playback_qa.dart` as the debug target from `mobile/`, passing the fixture and host build defines. Mac and phone must each use their own explicit debug launch; this source change does not build, sign, install, connect to a device, alter DNS, activate a CDN route, or validate native playback. Do not enable analytics consent to obtain QA evidence. Stop after the bounded owned-fixture session and close the app to dispose the player.

This is rendition parity during migration, not a claim that derivative playback uses B2. CDN activation, invalidation safety, native timing and real frame/network evidence remain separate release work.
